# Roleta de Sorteio

Sistema de sorteio em roleta em um único arquivo HTML, que roda offline em qualquer navegador (Safari, Firefox, Chrome).

## Como usar
Abra o arquivo `roleta-sorteio.html` com duplo clique.

## Recursos
- **Roleta:** botão Girar, tempo de giro configurável, tela cheia (só a roleta e o botão), confete e palmas.
- **Cadastro:** itens com probabilidade em % (soma exatamente 100% para girar), opção "Não repetir itens já sorteados".
- **Relatório:** itens sorteados com data e hora (ou agrupados por quantidade), comparação entre probabilidade e resultado real, exportação em CSV.

Os dados ficam salvos no próprio navegador (localStorage).
